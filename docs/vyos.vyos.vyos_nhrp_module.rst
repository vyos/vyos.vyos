vyos.vyos.vyos_nhrp

**NHRP resource module**


Version added: 7.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- This module manages the Next Hop Resolution Protocol (NHRP) configuration of tunnel interfaces on devices running VyOS, as used for DMVPN.

Notes
-----

.. note::
   - Tested against VyOS 1.5.1.
   - This module works with connection ``network_cli``.
   - The tunnel interfaces themselves (encapsulation, source, addresses) are managed with :ref:`vyos.vyos.vyos_interfaces <vyos.vyos.vyos_interfaces_module>` and :ref:`vyos.vyos.vyos_l3_interfaces <vyos.vyos.vyos_l3_interfaces_module>`, and their IPsec protection with :ref:`vyos.vyos.vyos_vpn_ipsec <vyos.vyos.vyos_vpn_ipsec_module>`.
   - VyOS requires tunnels used by NHRP to have a /32 address.



Examples
--------

.. code-block:: yaml

    # Using merged

    # Before state:
    # -------------
    #
    # vyos@vyos:~$ show configuration commands | grep 'protocols nhrp'
    #

    - name: Configure a DMVPN hub tunnel
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun0
              authentication: secret
              holdtime: 300
              multicast:
                - dynamic
              redirect: true
              registration_no_unique: true
        state: merged

    # Task output
    # -----------
    #
    #    commands:
    #      - set protocols nhrp tunnel tun0 authentication 'secret'
    #      - set protocols nhrp tunnel tun0 holdtime 300
    #      - set protocols nhrp tunnel tun0 redirect
    #      - set protocols nhrp tunnel tun0 registration-no-unique
    #      - set protocols nhrp tunnel tun0 multicast dynamic

    # Using merged, on a spoke

    - name: Configure a DMVPN spoke tunnel
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun0
              authentication: secret
              shortcut: true
              nhs:
                - tunnel_ip: dynamic
                  nbma:
                    - 192.0.2.1
              multicast:
                - dynamic
        state: merged

    # Task output
    # -----------
    #
    #    commands:
    #      - set protocols nhrp tunnel tun0 authentication 'secret'
    #      - set protocols nhrp tunnel tun0 shortcut
    #      - set protocols nhrp tunnel tun0 multicast dynamic
    #      - set protocols nhrp tunnel tun0 nhs tunnel-ip dynamic nbma 192.0.2.1

    # Using replaced

    # Before state:
    # -------------
    #
    # set protocols nhrp tunnel tun0 authentication 'secret'
    # set protocols nhrp tunnel tun0 holdtime '300'
    # set protocols nhrp tunnel tun0 multicast 'dynamic'
    # set protocols nhrp tunnel tun0 redirect

    - name: Replace the configuration of tun0
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun0
              authentication: secret
              multicast:
                - dynamic
        state: replaced

    # Task output
    # -----------
    #
    #    commands:
    #      - delete protocols nhrp tunnel tun0 holdtime
    #      - delete protocols nhrp tunnel tun0 redirect

    # Using overridden

    # Before state:
    # -------------
    #
    # set protocols nhrp tunnel tun0 authentication 'secret'
    # set protocols nhrp tunnel tun1 shortcut

    - name: Override the NHRP configuration with one tunnel
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun0
              authentication: secret
        state: overridden

    # Task output
    # -----------
    #
    #    commands:
    #      - delete protocols nhrp tunnel tun1

    # Using deleted

    - name: Delete the NHRP configuration of one tunnel
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun1
        state: deleted

    - name: Delete all NHRP configuration
      vyos.vyos.vyos_nhrp:
        state: deleted

    # Task output (all NHRP configuration)
    # ------------------------------------
    #
    #    commands:
    #      - delete protocols nhrp

    # Using gathered

    - name: Gather the NHRP configuration
      vyos.vyos.vyos_nhrp:
        state: gathered

    # Task output
    # -----------
    #
    #    gathered:
    #      tunnels:
    #        - name: tun0
    #          authentication: secret
    #          holdtime: 300
    #          multicast:
    #            - dynamic
    #          redirect: true

    # Using rendered

    - name: Render the commands for a spoke tunnel
      vyos.vyos.vyos_nhrp:
        config:
          tunnels:
            - name: tun0
              nhs:
                - tunnel_ip: 10.0.0.1
                  nbma:
                    - 192.0.2.1
        state: rendered

    # Task output
    # -----------
    #
    #    rendered:
    #      - set protocols nhrp tunnel tun0 nhs tunnel-ip 10.0.0.1 nbma 192.0.2.1

    # Using parsed

    - name: Parse NHRP configuration from device output
      vyos.vyos.vyos_nhrp:
        running_config: |
          set protocols nhrp tunnel tun0 map tunnel-ip '10.0.0.2' nbma '192.0.2.2'
          set protocols nhrp tunnel tun0 shortcut
        state: parsed

    # Task output
    # -----------
    #
    #    parsed:
    #      tunnels:
    #        - name: tun0
    #          map:
    #            - tunnel_ip: 10.0.0.2
    #              nbma: 192.0.2.2
    #          shortcut: true
